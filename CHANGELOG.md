# Changelog

All notable changes to this project will be documented here.

## 0.1.0 - 2026-08-08

- Added signed Delta Exchange v2 REST client.
- Added helpers for every endpoint group in the bundled API documentation.
- Added async WebSocket streaming, current `key-auth`, heartbeats, reconnect, and resubscribe.
- Added typed exceptions, environment selection, and pagination.
- Added PyPI packaging metadata, documentation, and tests.
